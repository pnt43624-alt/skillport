# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | yes       |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Email the maintainer via the GitHub account that owns this repository, or open a **private** security advisory on GitHub.

Include:

- SkillPort version
- Reproduction steps
- Impact assessment

We aim to acknowledge reports within 72 hours.
